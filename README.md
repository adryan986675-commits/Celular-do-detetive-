# Celular-do-detetive-
🕵️ Celular do detetive é um jogo de investigação e mistério onde você se torna um detetive! Explore uma cidade cheia de segredos, procure pistas, interrogue personagens, conecte evidências e resolva 100 casos. Personalize seu avatar, desbloqueie lugares, suba de nível e descubra uma grande história cheia de mistérios! 🔎🧩🏆
